As of September 15th, 2026, the program is in a MVP (minimum viable product) state.

Hello, I am Dominic Lyu. The programmer behind the code in this project. The goal of this project was to learn Pygame and understand how to make a basic video game. This program is a recreation of SPACE INVADERS. An old arcade game that features endless rounds, procedurally generated enemies, shooting, and movement.

I used the following:

Visual Studio 2022
Python 3.13
Pygame (2.6.1)
